# Glossary

## ASR

Automatic Speech Recognition. Audio-to-text conversion.

## WebGPU

Browser GPU backend, usually the fastest execution path.

## WASM

WebAssembly. CPU backend with broad compatibility.

## COOP / COEP

Browser headers required for cross-origin isolation and WASM multithreading.

## Chunking

Splitting audio into processing windows.

## Dedupe

Removing overlap duplicates across chunk boundaries.

## VAD

Voice Activity Detection. Speech/silence boundary detection.

## LUFS

Perceived loudness unit used in audio normalization.

## Progressive mode

Segment-by-segment processing to reduce memory pressure.

## TelemetryCollector

Collector for runtime events, timers, alerts, and memory snapshots.

## CRI / CRO / CRS

Report formats generated by LLM modules.

## Context window

Maximum number of tokens a model can read in one request.

## Dtype

Model numeric precision/runtime format (q4, q8, fp16, etc.).

## Gradio

Remote inference provider/API frontend used by cloud mode.

## Hugging Face Inference

Cloud inference service used by Whisper and cloud LLM mode.

## Mistral API

Cloud API used for audio transcription and LLM generation.

## Diarization

Detection and labeling of audio participants (speakers) per segment.

## Speaker assignment

Manual mapping from a technical speaker id to a displayed/exported first/last name.

## Export run snapshot header

Metadata block written in export headers (`VTT`/`SRT`/`JSON`/`telemetry`) describing effective run settings/runtime.
